    Project Description:
    The project consists of replacing the existing ultraviolet
    (UV) disinfection system with an improved automatic
    cleaning system and enhanced capability to control the
    target delivered UV dosage based on flow and
    transmittance variation. This project is identified in the
    2012 Water Reclamation Plant Master Plan.


    Project Justification:
    The existing UV system requires cleaning due to biological
    growth build up on the bulbs. The system is also aging and
    the availability of replacement parts for the control
    system is limited. A new system is anticipated to improve
    the reliability of operation.
